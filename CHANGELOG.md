# Changelog

## 0.1.0 — MVP
- Local speech recognition: Silero VAD segmentation + GigaAM-v3 e2e RNNT, incremental during the visit.
- Automatic first-run model download with resume, disk-space check and SHA-256 verification; built-in self-test.
- Complaints and history of present illness from evidence-validated facts; warnings; source trace.
- Review screen with editing, copy, copy-all, transcript; global hotkeys; tray; always-on-top.
- Privacy: no audio retention, PHI-redacted logs, credentials in Windows Credential Manager.
- Windows installer (per-user), CI build/install/self-test/uninstall.
