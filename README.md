# Medical Visit Assistant (MVA) 0.1.0

Windows-приложение для амбулаторного врача: слушает приём, **локально** распознаёт речь
моделью **GigaAM-v3** и формирует черновики двух разделов — **ЖАЛОБЫ** и **АНАМНЕЗ ЗАБОЛЕВАНИЯ**.
Врач проверяет, при необходимости правит и копирует текст в MediLog.

## Что делает
- запись разговора с выбранного микрофона, индикатор «● Идёт приём», таймер и тонкий индикатор уровня;
- локальное распознавание: Silero VAD → сегменты 0,3–22 с → GigaAM-v3 `v3_e2e_rnnt` (пунктуация и нормализация);
- инкрементальное распознавание во время приёма, после «Завершить» дорабатываются только последние фрагменты;
- извлечение **только подтверждённых фактов** с привязкой «факт → сегмент → время → цитата»;
- детерминированная проверка: отрицания, числа, длительность, сторона, препараты, уточнения вроде «гнойные»;
- предупреждения «ПРОВЕРИТЬ» (неоднозначности не попадают в документ);
- редактирование, «Копировать» / «Копировать всё», «Показать источник» и «Показать расшифровку».

## Чего НЕ делает (MVP)
Диагнозы, МКБ, назначения, рекомендации по лечению, осмотр/ЛОР-статус, эпикриз, рецепты,
автосохранение карты, автоподписание, автоматические клики в MediLog. Результат всегда **черновик**.

## Установка
1. Запустите `MedicalVisitAssistant-0.1.0-Setup.exe` (Windows 10/11 x64, права администратора не нужны).
2. Установщик ставит приложение в `%LOCALAPPDATA%\Programs\MedicalVisitAssistant` и создаёт ярлык.

Python, PyTorch, GigaAM, FFmpeg, Git и терминал **не нужны** — всё необходимое входит в установщик.

## Первый запуск
Мастер из пяти шагов:
1. **Микрофон** — выбор устройства (по умолчанию системный).
2. **GigaAM** — модель (~450 МБ) скачивается автоматически с официального CDN, проверяется
   по SHA-256 и загружается; сразу распознаётся встроенная тестовая запись, и показывается результат.
   Прерванная загрузка продолжается с места остановки. Модель хранится в
   `%LOCALAPPDATA%\MedicalVisitAssistant\models` и при обновлении приложения заново не скачивается.
3. **ИИ** — OpenAI-совместимый сервис (облачный или локальный сервер клиники); шаг можно пропустить.
4. **Проверка** — запись 6 секунд с микрофона и распознавание.
5. **Готово**.

## Работа на приёме
| Действие | Клавиши |
|---|---|
| Начать / завершить приём | **Ctrl+Alt+R** |
| Копировать жалобы | **Ctrl+Alt+1** |
| Копировать анамнез | **Ctrl+Alt+2** |
| Новый приём | **Ctrl+Alt+N** |

В Windows горячие клавиши глобальные: работают, даже когда в фокусе MediLog. Их можно изменить в
«Настройки → Горячие клавиши». Окно по умолчанию поверх других; это отключается в «Настройки → Общие».

## Настройка ИИ
«Настройки → ИИ»: Base URL, модель, API-ключ и «Проверить подключение». Ключ хранится в
диспетчере учётных данных Windows и никогда не попадает в файлы. Если указан облачный адрес, приложение
явно пишет: «Для формирования документа используется облачная модель». В облако уходит только
**текст** расшифровки, аудио — никогда. Для работы без облака укажите локальный сервер
(например, `http://localhost:11434/v1`).
Без ИИ приложение всё равно распознаёт речь; расшифровку можно скопировать, а анализ повторить позже.

## Конфиденциальность
Схема: Микрофон → локальный VAD → локальный GigaAM → текст → (по желанию) настроенный ИИ.
Аудио удаляется сразу после распознавания, история приёмов не сохраняется, в журналах нет
медицинского текста. Подробности — в [PRIVACY.md](PRIVACY.md).

## Устранение неполадок
- **«Нет доступа к микрофону»**: Параметры Windows → Конфиденциальность → Микрофон → разрешить настольным приложениям.
- **«Слишком тихий сигнал»**: выберите другой микрофон или увеличьте уровень записи в Windows.
- **Модель не скачивается**: проверьте интернет и нажмите «Повторить». Нужно около 1 ГБ свободного места.
- **ИИ недоступен**: расшифровка сохраняется; нажмите «Повторить анализ» или «Копировать расшифровку».
- **Диагностика**: «Настройки → Диагностика» — проверка системы, тест GigaAM, экспорт отчёта без медицинских данных.
- Журнал: `%LOCALAPPDATA%\MedicalVisitAssistant\logs\mva.log` (без текста приёма).

```bash
uv run mva                             # GUI
uv run mva --self-test --mic-seconds 6 # скачать/загрузить GigaAM, распознать WAV и микрофон
uv run pytest tests/unit tests/integration tests/clinical
uv run pytest -m model tests/audio tests/e2e   # с реальной моделью
```
